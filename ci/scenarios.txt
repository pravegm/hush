# slider unless a pilot drives it or lid=<0…1> holds it).
# name|demo args (-hushDemo, keys in design/ROUND-1.md "Demo mode")|wait s|caption (what the frame should show)|expect
#  - wait: a freezeOn=<tag> scenario waits for the app's "HUSH-T freeze <tag>" line instead (up to max(wait, 60) s),
#    then 2 s; it is captured anyway (and flagged no-freeze in captures.tsv) if the line never comes.
#  - expect: optional extended regex the app log must contain at capture time (reported, never fatal).
#  - No "|" inside a field, the expect regex included: R3's 13b expect `(freeze |event )?creak` was split at its "|"
#    and could never match (R4: screenshots.sh now warns about a stray extra column).
#  - Names are zero-padded so the artifact sorts in reading order.
#  - The app icon is not a scenario: ci.yml renders it in its own step (screen=icon → app-icon-1024.png).
#  - R3: an optional 6th column that starts with "-" is extra launch arguments (ci/screenshots.sh), used by the Large
#    Dynamic Type frames 41–47.
# R4 timing notes (design/notes/ci-R4.md):
#  - An event freeze (bite, bank, relic, torchLow, creak) stops the session `freezeDelay` s after the event (default 0.3,
#    bank 1.25, relic 1.65), and the scene keeps drawing for GameController.sceneHoldDelay (0.4 s) more before it is
#    paused. So the scene's moment age in the frame is about freezeDelay + 0.4 s. The bank group ("Hushed!", "BANKED
#    +N", "Hush Chain ×1.N") shows 0.15–1.15 s and the loot flies 0.12–1.0 s (SceneMoments), so a bank frame that must
#    show the toast and the flying loot uses freezeDelay=0.25 (age ≈ 0.65 s); the counter only equals the sum at the
#    default 1.25 (14b). "CREAK!" shows 0–0.7 s and fades from 0.45 s, so the creak frames use freezeDelay=0 (age ≈ 0.4 s).
#  - A state freeze (ready, reveal, stirring, waking) is the FIRST frame of that state; `freezeAfter=<s>` delays it.
#
